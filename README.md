# Expense Tracker

A simple and responsive Expense Tracker web application built using **HTML, CSS, and JavaScript**.

The application allows users to manage income and expenses, view financial summaries, filter transactions, and store transaction data using browser Local Storage.

## Features

- Add income and expense transactions
- Enter amount, category, date, and description
- Edit existing transactions
- Delete transactions
- View total income
- View total expenses
- View current balance
- Filter transactions by income or expense
- Filter transactions by category
- Store transactions using Local Storage
- Data remains available after refreshing the page
- Monthly income and expense summary
- Category-wise expense chart
- Form validation and helpful error messages
- Responsive design for desktop and mobile screens

## Validation

The application validates:

- Transaction type
- Amount
- Category
- Date
- Description
- Positive transaction amount

Helpful error messages are displayed when invalid information is entered.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
- HTML Canvas

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. The Expense Tracker application will be displayed.

**No additional installation or dependencies are required.**

> For development, the application can also be run using a local HTTP server.

## Data Storage

The application uses browser **Local Storage** to save transaction data. The data remains available after refreshing the page when using the same browser.
